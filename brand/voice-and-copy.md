# Voice and copy

## Voice

Customer-facing language is Serbian Latin by default. It is direct, calm,
helpful, and specific. Sound like an experienced fishing-shop colleague who
respects the customer's time—not an advertising slogan generator.

## Rules

- Lead with what happened or what the person can do next.
- Prefer short sentences and familiar verbs.
- Use specialist terms where precision matters; explain them when beginners
  may not know them.
- Do not manufacture urgency, scarcity, popularity, or trust.
- Avoid exclamation marks except for genuine warnings.
- Never blame the user for an error.
- Button labels use a clear action: `Postavi oglas`, `Sačuvaj`, `Pošalji poruku`.
- Preserve Serbian characters: `č ć ž š đ`.

## Preferred product terms

| Use | Avoid unless technically necessary |
| --- | --- |
| oglas | ad, listing |
| postavi oglas | publishuj, submituj |
| prijava / registracija | login / signup |
| sačuvaj | save |
| prodavac | vendor |
| mašinica | reel in customer-facing Serbian |
| štap | rod in customer-facing Serbian |

## Message pattern

For errors and blocked actions:

```text
Plain result. What the person can do next. Optional technical detail only if it
helps them recover.
```

Example: `Fotografija nije otpremljena. Pokušajte ponovo ili izaberite datoteku
manju od 10 MB.`
