# Workflow: product brand audit

## Scope first

Name the routes, breakpoints, states, user role, and evidence available. A
desktop homepage screenshot is not evidence about mobile listing creation.

## Inspect

Check:

- logo variant, proportions, clear space, and background;
- token use and unexplained hard-coded color;
- typography hierarchy, language, and terminology;
- spacing, radius, border, shadow, and density consistency;
- icons, SVG grammar, semantic fit, and small-size clarity;
- action hierarchy and status/error color semantics;
- contrast, focus, labels, motion, and responsive behavior;
- loading, empty, success, error, and destructive states;
- whether decorative choices obscure marketplace facts.

## Report

For every finding provide:

1. evidence (route, component, selector, screenshot, or file);
2. observable issue;
3. customer/brand impact;
4. priority P0–P3;
5. specific recommendation;
6. acceptance check.

Consolidate repeated symptoms under a shared root cause. End with the three
highest-leverage actions and a formal review verdict.
