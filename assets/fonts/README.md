# Manrope for social artwork

Unmodified variable TrueType font from the [Google Fonts Manrope directory](https://github.com/google/fonts/tree/fb629caaa15ad25c051089c98f09cf6c8e30a86b/ofl/manrope),
pinned to commit `fb629caaa15ad25c051089c98f09cf6c8e30a86b`.
Original filename: `Manrope[wght].ttf`. Local filename: `Manrope-variable.ttf`.
SHA-256: `d0639be45d0af36e798172419d7bd173c4bd4f29e2b76cbb69db1d11bf8b0a40`.
Redistributed under the adjacent SIL Open Font License, `OFL.txt`.

Use the complete font, including Serbian Latin glyphs, at weights 400, 500 and 800.
Do not rely on network font requests, a system fallback, or the developer's font cache.
Self-contained SVG derivatives embed the font; include the license when distributing
editable SVG source. JPEGs are rendered artwork, not font software.
